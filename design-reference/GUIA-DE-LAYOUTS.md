# Guia de Layouts para Redes Sociais

Cada layout documentado aqui é um **padrão reutilizável**.  
Para aplicar a um cliente novo: troque a paleta, a fonte e a foto — a estrutura permanece.

---

## Como usar este guia

Cada layout tem:
- **Nome** — referência curta para citar no briefing
- **Estrutura** — onde ficam os elementos na tela
- **Hierarquia** — o que o olho lê primeiro, segundo, terceiro
- **Regras de adaptação** — o que pode mudar, o que não pode
- **Funciona para** — tipos de cliente / contexto de uso
- **Não funciona para** — quando evitar

## Critérios de Qualidade

Um bom post de redes sociais atende:

1. **Hierarquia clara** — em 3 segundos dá para saber o que é o post
2. **Respiração** — espaço em branco não é desperdício, é conforto visual
3. **Consistência tipográfica** — no máximo 2 famílias de fonte por post
4. **Contraste funcional** — texto legível sobre qualquer fundo
5. **Ponto focal único** — foto, headline ou cor chamam atenção primeiro — nunca os três juntos
6. **Margem de segurança** — nenhum elemento colado na borda
